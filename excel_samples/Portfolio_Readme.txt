EXCEL OPERATIONS PORTFOLIO SAMPLE

A self-directed demonstration by Emmanuel Sanchez.

WHAT'S INCLUDED
- Ops Dashboard: task, receivables, completion and budget metrics with linked charts.
- Task Tracker: sortable task table, priority/status dropdowns, due-date warnings and hours variance.
- Invoice Control: balance, aging, collection status and action tracking.
- Budget Review: monthly budget-versus-actual calculations and variance indicators.
- Macro Guide: setup notes for four companion VBA automations.
- PortfolioAutomation.bas: importable VBA source module.

VBA AUTOMATIONS
1. RefreshPortfolioDashboard — recalculates the workbook and updates dashboard metrics.
2. AddPortfolioTask — collects task details and appends a new row to the structured task table.
3. ExportDashboardPDF — exports the dashboard as a dated PDF.
4. CreateOverdueReport — produces a separate action report of overdue tasks and invoices.

INSTALLING THE VBA SOURCE
1. Open the workbook in Excel desktop.
2. Press Alt+F11 to open the VBA editor.
3. Choose File > Import File and select PortfolioAutomation.bas.
4. Return to Excel and save a copy as an Excel Macro-Enabled Workbook (.xlsm).
5. Run a procedure from Developer > Macros. Optional buttons can be assigned from Developer > Insert.

This .xlsx contains no embedded macros. The companion .bas file is VBA source to import into Excel. The code is designed for the worksheet and table names in this sample; it has not been executed in a Microsoft Excel session here.

PORTFOLIO DESCRIPTION
Designed an Excel operations dashboard that brings task tracking, accounts-receivable follow-up and budget-versus-actual reporting into one workbook. Added structured tables, formula-driven KPIs, validation dropdowns, overdue alerts, variance analysis, linked charts and VBA automations for task intake, refresh, PDF export and exception reporting. Used fictional data for demonstration; this is a self-directed sample, not a client engagement.
